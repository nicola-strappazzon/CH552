# Button and RGB LED

## Description

Press the button to cycle through red, green, blue, and off.

## Schematic

![Button and RGB LED circuit](/assets/src/button_led_rgb/schematic.png)

## Features

- Button on P3.2.
- Red on P3.4, green on P3.3, and blue on P1.1.
- Button debounce delay.
