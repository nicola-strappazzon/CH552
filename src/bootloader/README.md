# Bootloader

## Description

Jump to the built-in bootloader whenever the MCU starts.

## Schematic

No example schematic is included. See the [minimum circuit](/README.md#minimum-circuit).

## Features

- Disables interrupts before the jump.
- Uses bootloader address `0x3800`.

## Additional information

See [Bootloader](/doc/bootloader.md) for the normal button-based upload procedure.
